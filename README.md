## 🚀 Что нового в версии 1.0.3

- **🛠️ Исправление затирания медиа и текста**: Устранена проблема, при которой добавление фото удаляло введённый текст поста, а отправка текста сбрасывала прикреплённое медиа или альбом. Теперь медиа и текст органично дополняют друг друга.
- **🚫 Удаление нестабильного `copy_message`**: Публикация постов в каналы переведена на прямые нативные методы Telegram API (`send_photo`, `send_video`, `send_media_group` и др.) с явной передачей сформированного текста в качестве `caption`.
- **👀 Выделенная кнопка «Предпросмотр поста»**:
  - Кнопка `[👀 Предпросмотр поста]` добавлена в экранную Reply-клавиатуру при создании поста.
  - Инлайн-кнопка `[👀 Предпросмотр поста]` (`post_refresh_preview`) добавлена в меню управления постом.
- **🎯 Изолированные FSM-состояния**: Добавлены состояния `PostCreator.edit_text` и `PostCreator.edit_media`, благодаря чему правка текста гарантированно не затрагивает медиафайл, а смена медиа сохраняет ранее введённый текст.
- **🪶 Сверхлёгкий движок миграций (`migrations.py`)**: Автономная система версионирования схемы БД на чистом `aiosqlite` с автоматическим накатыванием миграций при запуске бота.
- **🐧 Серверная оптимизация**: Все скрипты запуска (`start.sh`, `Dockerfile`, `docker-compose.yml`) приведены к стандарту LF с выставленными правами на исполнение (`0755`).

## 🚀 Что нового в версии 1.0.2

- **⚡️ Полный переход на асинхронный `aiosqlite`**: Устранена критическая ошибка синхронного ввода-вывода. База данных больше не блокирует главный Event Loop Python при одновременных запросах или массовых рассылках.
- **🔌 Долгоживущее подключение и режим WAL**: Внедрено постоянное соединение `aiosqlite` без оверхеда на переоткрытие файла с диска, включены прагмы `PRAGMA journal_mode = WAL;`, `PRAGMA synchronous = NORMAL;`, `PRAGMA busy_timeout = 5000;`.
- **🛡️ Реальное каскадное удаление (Foreign Keys ON)**: Включена прагма `PRAGMA foreign_keys = ON;` — каскадное удаление постов, медиа, голосов и прав каналов теперь гарантированно очищает осиротевшие записи.
- **🔄 Надёжный движок версионированных миграций**: Заменены хрупкие конструкции `try/except OperationalError: pass` на транзакционный механизм `schema_migrations`.
- **📸 Поддержка медиагрупп (Альбомов)**: Создана отдельная связанная таблица `post_media` для отправки и управления подборками из 2–10 фото и видео через `send_media_group`.
- **✨ Новые фичи Telegram Bot API**:
  - **`show_caption_above_media`**: Выбор позиции текста — сверху над картинкой/видео или снизу.
  - **`has_spoiler`**: Интерактивный блюр-спойлер для медиафайлов и альбомов.
  - **`CopyTextButton`**: Кнопка быстрого копирования промокода, адреса или текста в буфер обмена в один тап.
  - **`LinkPreviewOptions`**: Тонкая настройка сниппетов ссылок (показ превью над текстом, авто или полное отключение).
  - **`send_paid_media` (Telegram Stars)**: Продажа доступа к фото/видео/альбомам за Telegram Stars (от 1 до 2500 звёзд).
  - **`send_poll` (Опросы и викторины)**: Нативная публикация опросов в каналы с переголосованием и мультивыбором.
  - **`<blockquote expandable>` (Сворачиваемые цитаты)**: Однокликовое сворачивание длинных текстов в элегантные цитаты.
  - **`delete_all_message_reactions` (Очистка реакций)**: Модерация и очистка реакций на канале прямо из истории постов.
  - **Компактные таблицы**: Новый режим `style="compact"` для аккуратного форматирования данных.

## ✨ Возможности

### 📢 Управление каналами
- **Интерактивное добавление канала**: Выберите канал прямо через интерфейс Telegram (кнопка «Поделиться каналом»). Бот автоматически проверит права администратора.
- **Безлимитное количество каналов**: Подключайте любое количество каналов.
- **Разделение по пользователям**: Каждый пользователь видит и управляет только своими каналами.

---

### ✍️ Конструктор постов
- **Поддерживаемые форматы контента**:
  - 📝 Текст (с форматированием)
  - 🖼️ Фото (с подписью)
  - 🎬 Видео (с подписью)
  - 📎 Документ / файл
  - 🎵 Аудио
  - 🎙️ Голосовое сообщение
  - 🎞️ GIF-анимация
  - 🎭 Стикер

- **Умное обновление контента**: Если вы сначала отправили фото, а потом решили добавить текст — бот установит его как подпись к фото, не удаляя медиафайл.

---

### 🎨 Форматирование текста

Бот поддерживает четыре режима разметки:

| Режим | Описание |
|-------|----------|
| **Авто Telegram** | Сохраняет разметку «как есть» из вашего приложения: **жирный**, _курсив_, `код`, ~~зачёркнутый~~, кастомные эмодзи Premium |
| **HTML** | Ручные HTML-теги: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<a href="...">` |
| **Markdown** | Устаревший Markdown: `*жирный*`, `_курсив_`, `` `код` `` |
| **MarkdownV2** | Расширенный Markdown с экранированием спецсимволов |

---

### 📊 Генерация и форматирование таблиц

Бот позволяет создавать и красиво форматировать таблицы в постах для Telegram:

- **Автоматическая конвертация**: Отправьте Markdown-таблицу (вид `| Столбец 1 | Столбец 2 |`), и бот автоматически превратит её в аккуратную моноширинную рамку.
- **Стили таблиц**:
  - 📦 **Unicode Box** (`┌──┬──┐`, `│  │  │`, `└──┴──┘`) — эстетичная рамка со сплошными линиями.
  - 📐 **ASCII** (`+--+--+`, `|  |  |`, `+--+--+`) — классический стиль с символами `+` и `-`.
- **Конструктор таблиц**: Нажмите кнопку «📊 Таблица» -> «➕ Вставить новую таблицу» и отправьте данные через разделитель `|`.

---

### 🔗 URL-кнопки под постом

Добавляйте кнопки-ссылки под публикацией:

**Формат ввода:**
```
Текст кнопки - https://example.com
Кнопка 1 - https://site.com | Кнопка 2 - https://other.com - red
```

- Несколько кнопок в один ряд разделяются символом `|`
- Каждая строка — новый ряд кнопок

**🎨 Цвет кнопок** (поддерживает Telegram Bot API 9.4+):

| Параметр | Псевдоним | Цвет |
|----------|-----------|------|
| `primary` | `blue` | 🔵 Синяя (по умолчанию) |
| `success` | `green` | 🟢 Зелёная |
| `danger` | `red` | 🔴 Красная |

Пример: `Купить - https://shop.com - green`

---

### 👍 Кнопки реакций-голосований

Добавляйте интерактивные кнопки-реакции под постом:

- Вводите до **8 эмодзи** через пробел или запятую: `👍 👎 🔥 ❤️`
- Бот считает голоса: каждый читатель может поставить только **один голос**
- Результат отображается рядом с эмодзи: `👍 12  👎 3`

---

### 📅 Публикация

- **🚀 Немедленная публикация** — пост отправляется сразу
- **⏰ Отложенная публикация** — введите дату и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ` (МСК, UTC+3)  
  _Пример: `15.08.2025 14:30`_
- Встроенный планировщик на базе **APScheduler** — работает в фоне, не требует внешних очередей

---

### 📜 История постов

- Просматривайте все опубликованные посты по каждому каналу
- **Редактирование опубликованных постов**:
  - Изменение текста/подписи прямо на канале (через Telegram Bot API)
  - Изменение URL-кнопок под любым опубликованным сообщением
  - Поддержка **пересланных сообщений**: перешлите боту любое сообщение со своего канала — он распознает его и предложит меню редактирования

## 🛠️ Установка и запуск

### Требования
- Python **3.9+**
- Токен бота от [@BotFather](https://t.me/BotFather)
- Права администратора в целевом Telegram-канале

### 1. Клонировать репозиторий

```bash
git clone https://github.com/novirx-tg/postingpost.git
cd postingpost
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить конфигурацию

Переименуйте `.env.template` в `.env` и заполните:

```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 4. Запустить бота

```bash
python main.py
```
